# ResAIrch · AI 研究星图

一张可交互的 AI 研究地图，用来花几小时（而不是几个月）判断一个方向适不适合你。

7 个分支、26 个领域。点击任一星球，跃迁进入该领域的综述：

| 章节 | 内容 |
|---|---|
| 领域综述 | 这个领域在解决什么问题、怎么发展到今天、现在的格局 |
| 最前沿在做什么 | 截至 2026 年的主线与热点 |
| 有品味的 idea | 现在还值得做的选题，附「为什么有品味」和「最小实验」 |
| 入场需要什么 | 必须掌握 / 加分项 |
| 大家怎么做 | 典型数据规模、算力配置、代码底座、基准指标、大家通常在改什么、投稿去处，以及一篇论文的典型流程 |
| 适合你吗 | 快速自检 |
| 两周试错路线 | 按天安排的上手计划，做完就能判断要不要继续投入 |
| 必读论文 | 经典论文与前沿论文，链接到 Google Scholar |

## 使用

纯静态页面，不需要构建。直接打开 `index.html`，或者开启 GitHub Pages（Settings → Pages → Deploy from branch → `main` / root）。

- 拖拽平移，滚轮或双指缩放；放大后能看到每个领域的子方向
- `/` 聚焦搜索框，回车跃迁到第一个匹配结果
- 在综述页里用 `←` `→` 切换领域，`Esc` 返回星图
- 可以用 `#/24` 这样的链接直接打开某个领域

## 结构

```
index.html     页面骨架
style.css      样式
app.js         星图布局、平移缩放、跃迁动画、综述渲染
data/*.js      各领域内容（每个文件向 window.RA_DOMAINS 添加若干领域）
```

想新增或修改领域，编辑 `data/` 下对应文件即可，字段含义参考任意一个已有领域。
